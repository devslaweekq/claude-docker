# Changelog

## Baseline — 1.0.1 … 1.4.17 (2026-06-19 – 2026-10-28)

Condensed history of all releases up to and including 1.4.17. The per-release entries were merged
into this file; the full originals stay available in git history. Entries describe what the project
looks like as of 1.4.17, with intermediate fixes and reverts folded into the final result.

### Added

#### Launcher and sessions

- Passthrough mode (`launcher <claude args>`), `--exec` in `menu.sh`, argument forwarding in
  `launcher.bat`; `launcher` no longer auto-builds a missing image.
- `PROJECT_DIRS` multi-directory workspaces (project picker vs. full menu vs. cwd as scratch).
- `claude -v` / `cladock --version`; `launcher --install --force` re-runs PATH setup (one symlink only).
- Interactive MCP server selection screen in `menu.sh` (fzf multi-select, numeric fallback),
  re-runnable via the "Configure MCP servers" menu entry; state in `~/.claude-docker-mcp-configured` /
  `~/.claude-docker-mcp-managed`; user-added servers are never touched.
- Session cleanup entry ("Clean up old sessions…") in the per-folder session list: fzf multi-select
  (Tab / Ctrl+A / Enter / Esc), `Delete N session(s)? [y/N]` confirmation, list refreshes in place;
  `sessions.js --delete <cwd> <id...>`. Only the current folder's sessions are ever affected.
- Seeded user-level `CLAUDE.md` (`claude-defaults/CLAUDE.md`), copied on first start and never
  overwritten. Shipped rules: ComfyUI "draft cheap, finalize once" and "always give commit text"
  (single line, under 100 chars).
- `scripts/utils/bump-version.sh` + `npm run bump <version> <slug>`.

#### Optional services

- **ComfyUI** (`slaweekq/comfyui`): CUDA image, Z-Image Turbo `txt2img` and `edit` (img2img)
  workflows, `launcher --comfyui`, ComfyUI MCP entry; now a thin image that installs torch into a
  venv mounted at `${COMFYUI_HOME}/venv` (`/opt/venv`) on first run (`uv pip`, reinstalled when
  `requirements.txt` or the torch pin changes; the first `--comfyui` launch after upgrading takes a
  few extra minutes); publish workflow with disk cleanup and split build/push. Compose service `comfyui` (profile `comfyui`, host network,
  NVIDIA GPU) with bind mounts `~/claude-docker/comfyui/{models,output,user}`; the launcher exports
  `COMFYUI_HOME`; installers create these dirs and seed the default workflow into
  `user/default/workflows` (never overwritten; the `.deb` bundles it in
  `/usr/share/claude-docker/workflows/`).
- **Headroom** compression proxy (`launcher --headroom`) wired in through `ANTHROPIC_BASE_URL=http://localhost:8787`
  (previously the proxy sat idle), `HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY` from `.env` forwarded to
  its container (fixes `unsupported_country_region_territory`), state in
  `~/claude-docker/headroom/.headroom/`, tuned for speed via `HEADROOM_BACKGROUND_COMPRESSION`,
  `HEADROOM_TEXT_CRUSHER`, `HEADROOM_COMPRESSION_DEADLINE_MS=150`, `HEADROOM_KOMPRESS_MAX_TOKENS=50000`
  and `HEADROOM_COLD_START_FAST_PASS_TIMEOUT_SECONDS=5`; `PORTS.md` service port reference (ComfyUI `8188`, Headroom `8787`; compose uses
  `network_mode: host` instead of `ports:`).
- Reference-counted service lifecycle: shared services stop only when the last session exits
  (PID files in `/tmp/claude-svc-sessions/<service>/`, stale ones from crashed sessions auto-cleaned).
- **Playwright MCP runs on the host** (`localhost:8931`, `--isolated`, `--no-playwright` to opt
  out); needs `node`/`npx` on the host (the launcher prints a hint and continues without it);
  browser lookup `google-chrome` → `chromium` → Playwright Chromium (downloaded to
  `~/.cache/ms-playwright`), headed when a display exists, headless otherwise; ref-counted like the
  other services. Migration rewrites only an untouched `npx -y @playwright/mcp@latest` entry in
  `~/.claude.json` (customized entries are kept); the image is pulled once per launcher version
  (marker `~/claude-docker/.pulled-launcher-version`, skipped with `--build`).

#### Default MCP servers and plugins

- `claude-mem@thedotmack` plugin and `thedotmack` marketplace in default settings (worker UI on
  `http://localhost:37777`).
- Grafana MCP (via `uvx`, `--disable-write`, proxy bypass; `GRAFANA_URL` +
  `GRAFANA_SERVICE_ACCOUNT_TOKEN` in `.env`), Yandex Cloud MCP (`@yandex-cloud/mcp -s toolkit`, no
  env vars, browser OAuth on first use), Outline MCP (HTTP `<OUTLINE_URL>/mcp`, Bearer
  `OUTLINE_API_TOKEN`, base URL without trailing slash or `/mcp`; both documented in `.env.example`).
- Plugin marketplaces `devslaweekq/best-skills` and `doronz88/pymobiledevice3` enabled by default;
  new default settings (`editorMode`, `model`, `timeFormat`); "Native Ubuntu, NOT WSL" rule in the
  seeded user `CLAUDE.md`.

#### Image and tooling

- `assets/banner.png` README banner (generated with ComfyUI via the `comfyui` MCP, text overlay
  with `jimp`).
- `jimp`, `uv`/`uvx`, `xclip` and `wl-clipboard` in the image; UTF-8 locale (Cyrillic, CJK, etc.);
  Wayland / X11 clipboard passthrough for non-ASCII paste.
- `build.sh` / `push.sh` take `--claude|--comfyui|--all`; npm scripts `build:claude`, `build:comfyui`,
  `push:claude`, `push:comfyui`.
- Docker images tagged `:<version>` alongside `:latest`; Docker Hub overview synced from README
  (`comfyui/README.md` for the comfyui image; needs a `DOCKER_PASSWORD` token with Read/Write/Delete
  scope).
- `CONTRIBUTING.md` (+ `## Contributing` in README), Dependabot (npm, Actions, Docker for root and
  `comfyui/`), CI with `npm audit` and Prettier check on every push and pull request.
- Project `CLAUDE.md` rules (English only, git workflow, version bumping, linked install files,
  never delete commented-out lines).

#### Packaging and distribution

- `.deb` package (`scripts/deb/`), curl/Docker auto-install in `scripts/install.sh` (`.deb`
  preferred on Debian/Ubuntu), GitHub Actions release workflow, signed APT repository on
  `gh-pages` for `apt upgrade` updates (key `/usr/share/keyrings/claude-docker.gpg`, list
  `/etc/apt/sources.list.d/claude-docker.list`, set up by both `install.sh` and `postinst`; published
  with `reprepro` on `v*` tag pushes).
- Auto-configured `~/.wslconfig` on WSL2 (75% of host RAM, all CPUs).

### Changed

- Repository restructured into a per-service monorepo (`claude-docker/`, `comfyui/`); git-clone
  entry point moved from `./launcher` to `claude-docker/launcher`; `certs/` lives at the repo root. **Breaking** for git-clone users (no
  shim at the old path); installed layouts (`.deb` / curl installer) are unaffected. The launcher
  auto-detects flat installed vs. git-clone layout.
- Base image `node:24.18.0-slim`; merged `apt-get` layers, dropped `ruby` and the redundant
  `@anthropic-ai/claude-code` install; ComfyUI base image `nvidia/cuda:13.4.3-base-ubuntu24.04`.
- **Breaking:** `.env` `PROJECT_DIR` replaced by `PROJECT_DIRS` (comma-separated project roots); each
  root's subdirectories mount at `/workspace/<name>` (e.g. `PROJECT_DIRS=/home/user/work`).
- ComfyUI user data moved from the `comfyui_user` named volume to host bind mounts; migrate with
  `docker volume rm claude-docker_comfyui_user`.
- Cleaner install output: `Then run:` shows the chosen command (via `/tmp/claude-docker-chosen-cmd`);
  the `newgrp docker` note appears only when the user is not yet in the `docker` group.
- ComfyUI `push.sh` builds automatically when run locally; `build.sh` has a CI mode
  (`DOCKER_USERNAME` from env).
- Release body contains only `changelogs/*.md` files changed in the current push.
- Docker publish workflow triggers only on image-affecting files; `softprops/action-gh-release` v3.
- Root README restyled (badges, `## Features`) and split into per-service READMEs.
- Seeded user `CLAUDE.md` reflowed to ~140 columns; dev dependencies updated.

### Removed

- Bundled `/parallel` and `/loki-report` slash commands (now skills in the `devslaweekq` plugin);
  `menu.sh` skips seeding when `claude-defaults/commands/` is absent, and commands already copied
  into `~/.claude/commands/` are left untouched.
- `COMFYUI_PATH` env-var approach (replaced by host-mounted `comfyui_user` volume).
- Baked-in Playwright + Chrome in the image (1.4.14, reverted in 1.4.15).

### Fixed

- Installer: no name prompt on re-install, `sudo -H -u` in `postinst`, APT repository setup
  permissions, shallow-clone empty release body, `install.sh` curl calls now have timeouts and retries.
- Cyrillic / non-ASCII copy and paste from the terminal (UTF-8 locale, Wayland/X11 clipboard,
  `.bashrc` locale line; `menu.sh` clears the screen with `\033[3J\033[2J\033[H` instead of
  `\033c`, which reset the terminal out of UTF-8).
- `NO_PROXY` / `no_proxy` defaults uncommented in `.env.example` so proxy bypass works out of the box.
- Plugin marketplace clones: HTTPS URLs instead of SSH, GitHub added to `NO_PROXY` (corporate
  proxy `CONNECT` failures), `claude-mem` `zod/v3` stop-hook error; `menu.sh` seeds the GitHub host key into
  `~/.ssh/known_hosts` and clears the git proxy for github.com.
- Launcher no longer lists the install dir's reserved subfolders (`home/`, `comfyui/`, `headroom/`,
  `certs/`) as projects when a `PROJECT_DIRS` root is the install directory.
- Grafana MCP `uvx` argument order; ComfyUI entrypoint crash without a mounted venv; broken
  `certs/` mount path on installed setups.
